# OpenCode Setup

Start OpenCode from the actual repository root.

Planned flow:
1. start OpenCode;
2. connect/select the desired worker model;
3. request the product PRD + worker task from R&D;
4. save it under `.ops/inbox/rnd/`;
5. execute with explicit `ROLE: WORKER`.

Do not run initialization that overwrites the governed root `AGENTS.md`.

No product PRD is bundled in this base package.
