# Runtime Role

Explicitly delegated `ROLE: WORKER` means WORKER; otherwise direct session is an IT ORCHESTRATOR. Account/model does not define authority. Workers return evidence, orchestrators review. Never create a global current-role marker. Read `contexts/can/docs/team/ROLE_PROTOCOL.md`.
