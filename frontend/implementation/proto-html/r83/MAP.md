- Tebakan Top-3: heuristik demo dari bentuk gambar (diberi label di layar), model aslinya milik partner.
- Kamera dan tangan: diganti mouse/keyboard. Ring jempol = tahan klik atau Enter/Spasi.
- Kuis penutup tidak ada.

- **Dua jenis tombol bundar** (`ui.js` `makeRing`, `SU.ringModeFor` di `hand.js`):
  - *cubit*: tanpa cincin progres, jalan saat dilepas. Contoh: Ayo!, Lanjut, Aku mengerti, Mulai Bab, Lempar, Gambar lagi, Taruh di sini, Mulai.
  - *diamkan 2 detik*: cincin progres, terisi kalau kursor diam di atasnya. Selama sedang mencubit di mana pun, cincin berhenti terisi, jadi coretan atau tarikan tidak pernah mengonfirmasi. Ini ciri khas game dan cuma dipakai buat keputusan penting: **Ya, itu namaku** (sampul), **Tebak Gambarku** (canvas), **Ya, ini …** (tebakan), **Kembali ke sampul** (penutup). Ring yang muncul di bawah kursor yang sedang diam menunggu kursor keluar dulu (latch).
  - Enter/Spasi tetap jalan: cubit = Enter sekali, diamkan = tahan Enter.
- **Kursor tangan** (`hand.js`): ring yang mengikuti titik sebenarnya dengan tau ±35 ms. Di atas tombol ring membesar dan oranye, tampilannya ditarik 25% ke tengah tombol (hanya tampilan, klik tetap di titik sebenarnya). Saat mencubit ring mengecil jadi titik. Di atas kertas gambar kursor tangan disembunyikan dan yang tampil kursor kanvas bawaan (`.sk-cursor`, ujung pena atau lingkaran hapus) tanpa jeda dan tanpa tarikan magnet. Mouse keluar jendela = ring abu-abu (tangan tidak terbaca). **H** = matikan/nyalakan simulasi. Keterangan singkat muncul sekali per sesi di atas kartu kamera.
- **Sampul**: gerbang (centang + Lanjut) tetap mouse biasa karena kamera belum nyala; kursor tangan hidup setelah kamera nyala. Cincin "Tahan jempol" diganti tombol cubit **Ayo!**. Penggaris nomor absen diganti **kenalan nama**: Momo bertanya "Siapa namamu?", siswa cubit tombol mik, sebut nama (Web Speech API `id-ID`, ini simulasi, STT asli dari riset Dias), Momo mengulang namanya, lalu siswa diamkan kursor di **Ya, itu namaku** atau cubit **Ulangi**. Kalimat seperti "nama saya rani putri" dibersihkan jadi "Rani Putri" (maks 3 kata). Mik tidak ada atau ditolak (sering di `file://`) = kolom ketik bertanda **Simulasi STT**. Nama disimpan di `su.state.name` (menggantikan `n`), dipakai Momo di kartu pertama ("Hai, Rani!").
- **Canvas**: alat pakai ikon alat (Pensil, Hapus, Mundur, Maju), bukan ikon gestur. "Selesai" jadi **Tebak Gambarku** (diamkan 2 detik).
- **Tebakan**: pilih baris Top-3 atau "Terima" = cubit (murah, bisa diganti), lalu label baru terkunci lewat **Ya, ini …** (diamkan 2 detik) atau **Ganti** (cubit). Tombol 1 2 3 tetap memilih. Momo berhenti bicara begitu siswa memilih (`S.hush`).
- **Jalan (level, kartu 1, kolam tinta)**: tidak ada lagi "tahan dunia = jalan ke arah kursor" atau seret halaman. Gantinya tombol di layar: cubit-tahan **Kiri/Kanan** = jalan, cubit **Lompat** = lompat (`SU.handPad`), duduk tepat di atas kartu kamera. Keyboard tetap.
- **Copy**: semua "tahan jempol", "telapak terbuka", "jari di kamera" diganti kalimat cubit/arahkan/diamkan.
- **Diuji** (Chrome headless 1280×720, tanpa error konsol): sampul sampai kartu dengan nama; kartu 1 jalan pakai tombol; kartu 2 dan 3; canvas → Tebak Gambarku (diam 2 detik) → tebakan (cubit baris 2 → Ya, ini Balok) → stiker Lempar → level 1 jatuh → Taruh di sini → main (Kanan + Lompat); pilih bab; penutup (kolam tinta pakai tombol, Kembali ke sampul = diamkan). Klik-tahan di cincin "diamkan" tidak mengonfirmasi (sengaja).
- **Belum**: kamera dan MediaPipe asli (sandbox tetap mouse), STT asli Dias, Safari/Firefox, layar sentuh.
