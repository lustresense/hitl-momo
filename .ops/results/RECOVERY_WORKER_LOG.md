### `tests/components/components.test.tsx` — Line 64 (pre-fix)
```ts
fireEvent.click(screen.getByRole("button", { name: /gambar ulang \\(revisi\\)/i }));
```
**Assessment:** ❌ BUG — BROKEN REGEX.

**Root cause analysis:**
- In a JS/TS regex literal `/pattern/`, backslash is the escape character.
- The file contained `\\(revisi\\)` inside the regex.
- In a regex, `\\` = one literal backslash; `(` = literal `(`.
- Therefore the pattern matched the string `gambar ulang \(revisi\)` — WITH actual backslash chars.
- The actual button text in `DecisionPanel` is `Gambar ulang (revisi)` — parentheses, no backslashes.
- Result: `getByRole` could not find the button and threw `TestingLibraryElementError`.

**Fix applied:**
```ts
fireEvent.click(screen.getByRole("button", { name: /gambar ulang \(revisi\)/i }));
```
- In a regex literal, `\(` escapes the `(` to match a literal `(`.
- Pattern now correctly matches `Gambar ulang (revisi)` (case-insensitive).
