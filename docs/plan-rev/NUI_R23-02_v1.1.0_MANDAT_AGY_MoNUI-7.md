| Nama | Nilai |
|---|---|
| `RESCUE_ENTER_MISS_MS` | 100 |
| `YOLO_INTERVAL_MS` | 100 (≤ 10 Hz) |
| `YOLO_MIN_SCORE` | 0,35 |
| `CROP_SCALE` | 1,6 |
| `POSITION_ONLY_AFTER_MS` | 500 (kotak ada, 21 titik tidak ada) |
| `LOST_PROMPT_AFTER_MS` | 2000 (tidak ada kotak dan tidak ada titik) |
| `RESCUE_TRACK_MAX_FAILS` | 3 |

**Transisi:**

| Dari | Kondisi | Ke | Aksi |
|---|---|---|---|
| NORMAL | `mpHand` tidak ada selama ≥ `RESCUE_ENTER_MISS_MS` | SEARCH | mulai jadwal YOLO |
| SEARCH | `mpHand` ada | NORMAL | hentikan YOLO |
| SEARCH | YOLO memberi kotak ≥ `YOLO_MIN_SCORE` dan crop memberi 21 titik | RESCUE_TRACK | kirim titik (`source: "rescue"`) |
| SEARCH | ada kotak, tapi tidak ada titik selama ≥ `POSITION_ONLY_AFTER_MS` | POSITION_ONLY | kirim `positionOnly` |
| SEARCH | tidak ada kotak dan tidak ada titik selama ≥ `LOST_PROMPT_AFTER_MS` | LOST | event untuk Momo |
| RESCUE_TRACK | `mpHand` ada | NORMAL | — |
| RESCUE_TRACK | crop dari titik terakhir gagal `RESCUE_TRACK_MAX_FAILS` kali berturut-turut | SEARCH | — |
| POSITION_ONLY | crop memberi 21 titik | RESCUE_TRACK | — |
| POSITION_ONLY | `mpHand` ada | NORMAL | — |
| POSITION_ONLY | kotak hilang selama ≥ `LOST_PROMPT_AFTER_MS` | LOST | — |
| LOST | `mpHand` ada, atau ada kotak + titik | NORMAL / RESCUE_TRACK | — |

Di `RESCUE_TRACK`, crop frame berikutnya diambil dari kotak 21 titik terakhir (skala `CROP_SCALE`), dijalankan maksimal 15 Hz.

## Lampiran H — env.sh, disk, mount, Range, Mendeley

### H.1 Isi `$LOCAL/env.sh`

```bash
# MoNUI-7 R23 — env AGY. Pakai: source /home/deano/monui7-local/env.sh
export LOCAL=/home/deano/monui7-local
export RC=<PATH_CLONE_RESEARCH_CAN>            # diisi di T00
export REPO=$RC
export WORK=$LOCAL/work
export DATA_ROOT=$LOCAL/data
export BIG_ROOT=/home/deano/mnt/monui7-data
export OWNER_IN=/home/deano/mnt/monui7-owner-in
export R20_TASK_PATH=$WORK/frontend/implementation/public/models/hand_landmarker.task
export SEED=20261120
export DISK_FLOOR_GB=15
export AGY_BUDGET_GB=32
export PIP_NO_CACHE_DIR=1
export MOUNT_CMD_DATA='<perintah sshfs persis untuk monui7-data>'        # diisi di T00
export MOUNT_CMD_OWNER='<perintah sshfs persis untuk monui7-owner-in>'   # diisi di T00

disk_ok() {
  local need=${1:-0} free_root free_local free used
  mkdir -p "$LOCAL"
  free_root=$(df -BG --output=avail / | tail -n 1 | tr -dc '0-9')
  free_local=$(df -BG --output=avail "$LOCAL" | tail -n 1 | tr -dc '0-9')
  free=$(( free_root < free_local ? free_root : free_local ))
  used=$(du -sBG "$LOCAL" 2>/dev/null | cut -f1 | tr -dc '0-9')
  echo "free=${free}G used_agy=${used}G need=${need}G"
  if [ $(( free - need )) -lt "$DISK_FLOOR_GB" ]; then echo "DISK_BLOCKED (sisa disk < ${DISK_FLOOR_GB}G)"; return 1; fi
  if [ $(( used + need )) -gt "$AGY_BUDGET_GB" ]; then echo "DISK_BLOCKED (jatah AGY > ${AGY_BUDGET_GB}G)"; return 1; fi
  echo DISK_OK
}
```

### H.2 Aturan disk

- GPU server ini juga dipakai Ujang dan deploy DEV. Sisa `/` minimal 15 GB; pemakaian AGY di `$LOCAL` maksimal 32 GB.
- Panggil `disk_ok <GB>` sebelum: unduhan, batch Range, ekstraksi, `pip install`, `npm ci`, training.
- Kalau `DISK_BLOCKED`: bersihkan `$DATA_ROOT/staging/` dulu. Jangan hapus apa pun di luar `$LOCAL`. Masih kurang: `BLOCKED (DISK)` dan laporkan angka `df`.

### H.3 Mount sshfs (sudah disiapkan Owner)

| Mount | Isi | Mode |

- Jangan `ssh` ke PC Windows untuk hal lain dan jangan membuka path lain di PC (termasuk `/mnt/c`, home `user_06`, folder proyek Ujang, `.env`). Jangan ubah kunci atau konfigurasi SSH, WSL, dan Windows.
