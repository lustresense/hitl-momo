# Visual R&D → IT Handoff

Dola AI is Visual R&D/reference generation.

- Exploration: `design/visual/references/dola/explorations/`
- Selected: `design/visual/references/dola/selected/`
- Optional handoff: `.ops/inbox/visual/`

A selected-reference note should state status, purpose, what to preserve, what not to copy, and user notes.

A filename containing `final` or an image being present in the folder does not itself constitute user approval.
