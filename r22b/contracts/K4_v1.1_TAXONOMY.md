## 1. Compositional State Model

Instead of forcing a single flat class to represent both finger posture and pinch contact, every hand frame produces a compositional `HandStateReading`:

```ts
interface HandStateReading {
  contact: "TOUCH" | "NEAR" | "OPEN";
  variant: "CLOSED" | "OK" | null;          // non-null when contact === "TOUCH"
  fingers: {
    thumb: "EXT" | "CURL" | "BETWEEN";
    index: "EXT" | "CURL" | "BETWEEN";
    middle: "EXT" | "CURL" | "BETWEEN";
    ring: "EXT" | "CURL" | "BETWEEN";
    pinky: "EXT" | "CURL" | "BETWEEN";
  } | null;
  threeVariant: "IMR" | "TIM" | "MRP" | null;
  derivedClass: K4DerivedClass;
}
```

## 3. Provenance & Anti-Contamination Rules (K4 / A06 / B05)

- `labelSource` MUST be one of: `MODEL_PREDICTION | RULE_DERIVED | USER_ACTION | DATASET_GT | UNKNOWN`.
- **Forbidden:** Training any supervised classifier (`M1`, `M1x`, `M2`) on `RULE_DERIVED` or `MODEL_PREDICTION` labels or unlabelled user telemetry.
- **Guided Capture Masking:** The first `700 ms` and last `300 ms` of every guided capture prompt step are tagged `truthMasked: true` and MUST be excluded from static training and per-class accuracy metrics.
- **Risky Pair Gates (K11):**
  - `FIST + PINCH_CLOSED` -> requires G1' onset gate + 2-frame / 300 ms post-FIST confirmation.
  - `PINCH_OK + FIVE` -> requires strict FIVE (`pinchRatio >= 0.55`, index PIP `>= 160 deg`, all 5 fingers clearly extended).
  - `THREE_MRP + PINCH_OK` -> marked `experimental: true`, requires G1' + strict contact separation.
