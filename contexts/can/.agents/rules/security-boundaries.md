# CAN Safety

Never automatically push or merge, force-push, run destructive reset, delete backups, leak tokens or record raw camera/student data. Check Owner authorization separately for audit/edit/commit/push/merge/deploy. Governance edits require explicit permission; product decisions need the DECISIONS approval protocol.
