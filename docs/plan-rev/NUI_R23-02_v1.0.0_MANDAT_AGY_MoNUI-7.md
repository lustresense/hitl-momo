## 0. Cara memakai dokumen ini (baca dulu sampai habis)

1. Kerjakan task sesuai nomor dan dependensinya. Jangan loncat, jangan gabung dua task.
2. Sebelum mulai satu task, baca bagian task itu sampai habis.
3. Task dianggap selesai hanya kalau semua kotak "Selesai kalau" tercentang **dan** buktinya ada di file.
4. Status hanya boleh salah satu dari: `PASS`, `FAIL`, `BLOCKED`, `NOT_TESTED`. Jangan tulis `PASS` tanpa output perintah yang tersimpan.
5. Kalau ada yang tidak sesuai dokumen, langsung STOP. Contohnya: file tidak ada, angka berbeda, atau perintah gagal dua kali. Lalu:
   - tulis `BLOCKED`,
   - tulis alasannya dan potongan error,
   - lapor ke Owner.

   Jangan menebak, jangan mengarang, jangan mencari jalan pintas.
6. Kerjakan satu perintah dalam satu waktu. Cek exit code-nya. Simpan output penting dengan `| tee <file>`.
7. Jangan mengubah file yang tidak disebut di task. Jangan menulis ulang file besar; edit bagian kecil saja.
8. Laporan ke Owner ditulis dalam Bahasa Indonesia yang sederhana dan pendek (format di §10).
9. Setiap selesai satu task, perbarui papan status §5 di file ini (AGENTS.md §3 mengizinkan memperbarui status di plan).

### T15 — Set gelap sintetis v0 (W-DATA)

Langkah:
1. Ambil 30% gambar train dari HaGRID, Open Images, IPN, dan HANDS secara acak dengan seed `20261120`.
2. Proses setiap gambar dengan urutan ini. Semua nilai adalah parameter prototipe dan dicatat ke `params.json`.
   1. sRGB → linear.
   2. gain ~ U(0,03; 0,25).
   3. Noise: shot ~ Poisson dengan skala U(0,5; 2,0), read ~ Gaussian σ U(1; 6)/255.
   4. Color cast: kalikan tiap kanal dengan U(0,85; 1,15).
   5. Clip.
   6. Linear → sRGB.
   7. JPEG dengan kualitas U(40; 85).
   8. Motion blur dengan p=0,3 (kernel 3–9 px).
   9. Glare backlight dengan p=0,2: gradasi terang di satu sisi latar.
3. Label disalin apa adanya.
4. Simpan hasilnya ke `$DATA_ROOT/yolo/monui7_hand_v0_dark/`.

Selesai kalau:
- [ ] jumlah gambar dan `params.json` tercatat,
- [ ] 1 contact sheet sudah dilihat.

### T18 — Pseudo-label gelap asli (W-DATA)

Algoritma:
1. **Usulan P1:** MediaPipe IMAGE mode (`num_hands=2`, `min_hand_detection_confidence=0.3`) di gambar asli. Kalau tidak ada tangan, ulangi di salinan yang ditingkatkan (gamma 0,5 lalu CLAHE dengan clip 2,0). Kotak = min/max landmark ditambah margin 15%.

4. **Celah video:** di video, celah ≤ 0,5 detik di antara dua frame konsensus diisi dengan interpolasi linear (ditandai `INTERPOLATED`).
5. **Yang tidak konsensus:** tidak dipakai.

Split: sisihkan 20% dari setiap sumber sebagai test, dibagi per sesi, orang, atau video.

QA per sumber:
1. Ambil 200 kotak konsensus acak dan buat contact sheet.
2. Lihat dan hitung presisinya.
3. Sumber diterima hanya kalau presisinya ≥ 95%.
4. Kalau < 95%: naikkan ambang IoU ke 0,7, lalu cek ulang **satu kali**. Kalau masih < 95%, sumber ditolak.

Hasil:

## Lampiran A — Rescue state machine

**State:** `NORMAL`, `SEARCH`, `RESCUE_TRACK`, `POSITION_ONLY`, `LOST`.

**Input per frame:**
- `t` (ms),
- `mpHand` (VIDEO mode menemukan tangan: ya/tidak),
- `yolo?` (`{box, score}` atau null, hanya kalau YOLO dijalankan),
- `crop?` (21 titik atau null, hanya kalau crop dijalankan).

**Konstanta** (parameter prototipe, ekspor sebagai `export const`):

| Nama | Nilai |
|---|---|
| `RESCUE_ENTER_MISS_MS` | 100 |
| `YOLO_INTERVAL_MS` | 100 (≤ 10 Hz) |
| `YOLO_MIN_SCORE` | 0,35 |
| `CROP_SCALE` | 1,6 |
| `POSITION_ONLY_AFTER_MS` | 500 (kotak ada, 21 titik tidak ada) |
| `LOST_PROMPT_AFTER_MS` | 2000 (tidak ada kotak dan tidak ada titik) |
| `RESCUE_TRACK_MAX_FAILS` | 3 |

**Transisi:**

| Dari | Kondisi | Ke | Aksi |
|---|---|---|---|
| NORMAL | `mpHand` tidak ada selama ≥ `RESCUE_ENTER_MISS_MS` | SEARCH | mulai jadwal YOLO |
| SEARCH | `mpHand` ada | NORMAL | hentikan YOLO |
| SEARCH | YOLO memberi kotak ≥ `YOLO_MIN_SCORE` dan crop memberi 21 titik | RESCUE_TRACK | kirim titik (`source: "rescue"`) |
| SEARCH | ada kotak, tapi tidak ada titik selama ≥ `POSITION_ONLY_AFTER_MS` | POSITION_ONLY | kirim `positionOnly` |
| SEARCH | tidak ada kotak dan tidak ada titik selama ≥ `LOST_PROMPT_AFTER_MS` | LOST | event untuk Momo |
| RESCUE_TRACK | `mpHand` ada | NORMAL | — |
| RESCUE_TRACK | crop dari titik terakhir gagal `RESCUE_TRACK_MAX_FAILS` kali berturut-turut | SEARCH | — |
| POSITION_ONLY | crop memberi 21 titik | RESCUE_TRACK | — |
| POSITION_ONLY | `mpHand` ada | NORMAL | — |
| POSITION_ONLY | kotak hilang selama ≥ `LOST_PROMPT_AFTER_MS` | LOST | — |
| LOST | `mpHand` ada, atau ada kotak + titik | NORMAL / RESCUE_TRACK | — |

Di `RESCUE_TRACK`, crop frame berikutnya diambil dari kotak 21 titik terakhir (skala `CROP_SCALE`), dijalankan maksimal 15 Hz.

| State guide | Kapan | Teks Momo |

- Angka 0,10, 3 detik, dan 10 detik adalah parameter prototipe.
